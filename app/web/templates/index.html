신규 안정층 (정본)

석회화 판정을 통과해 굳은 지식. 다음 질문에 주입되는 것이 이것뿐이다.

잠복 (부활 가능)

손상 판정으로 기각됐지만 삭제되지 않은 가지. 갈릴레오 문제.

폴립층 (활성면)

후보 노드. 스테이킹·실측으로 근거를 쌓고 승격 심사를 받는다. 판정 기준은 낯섦이 아니라 손상이다.

문답 (한 바퀴의 입구)

질문 → 정본 주입 → 기저 답 → P→I→C 구조화. 문답의 소유자는 사용자다.

한 바퀴: 질문 → 기저 LLM 답변 → P→I→C 구조화 → 사용자 승인/증분 → 스테이킹·실측 → 승격 판정(손상 시험) → 정본에 굳음 → 다음 질문에 주입.
기저 LLM 은 산출물 층위로만 접합된다 — 교체 가능한 부품이다.
