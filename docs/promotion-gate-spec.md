## 0. 불변 코어 루프 (모든 설계의 윗층)

다섯 코드베이스(H2A2H2 v1·v2, QAQA, dapsol, human-node)가 경제·관문·UI 를
전부 갈아엎는 동안 한 번도 바뀌지 않은 루프. 사용자 정식화 그대로 굳힌다:

```
사람이 묻는다
  → 기존 사람-AI 대화 중 참조할 것을 저비용 검색으로 먼저 보여준다
  → 부족하면 AI 에게 묻는다
  → 그 답변에 찬성 / 반대 / 추가 등의 행위를 해서 공유한다
```

- 이 루프는 사용자가 경험하는 **불변 표면**이다. 관문·시장·승격·잠복·배당은
  전부 이 루프의 **하부 기계**이며, 루프 문장에 등장하지 않는 것이 정상이다
  (장부는 사용자가 볼 필요 없다 — H2A2H2 고급 모드의 교훈).
- 4동사의 관문 대응: **찬성**=스테이킹/계승 · **반대**=반증(형제 노드) ·
  **추가**=증분/기여 · **공유**=폴립층 진입.
- ⚠ 현 MVP 구멍: 2단계(저비용 검색 선점)가 없다. 질문이 곧장 LLM 으로 간다.
  주입은 재사용이 아니다 — 주입은 LLM 을 *더 잘* 부르는 것이고, 선점 검색은
  LLM 을 *안* 부르는 것이다. §7 에서 표면으로 추가한다.

## 1. 원칙 (한 문장)

> **사람은 증거를 제출한다 — 반증, 실측치, 스테이크. 승격 판정은 그 증거에
> 대해 공개된 결정론적 함수가 내린다. 기저 LLM 은 관문 밖의 제보자다 — 표가 없다.**

세 절이 각각 함정 하나씩을 막는다: "사람이 직접 판정"이면 인기투표(대리변수
금지 위반), "함수가 비공개"면 은폐된 편집 노동의 재현(§B5 위반), "LLM 이
판정"이면 중력 5. 이 정식화는 H2A2H2 가 v1(LLM 패치 자동 적용)에서 v2("동의·
만족도는 닻이 아닙니다" — 사람은 수치 입력, 판정은 결정론 함수)로 이동하며
실제로 도달한 지점이다. 우리는 그 이동을 반복하지 않고 도착점에서 시작한다.

## 2. 전체 회로

```
문답 → 폴립                                        [포획 — 구현됨]
  → 관문 (증거 축적 → 공개 함수 판정)                [이 문서]
  → 정본
      → 1단 검색 재사용   (사람 소비, LLM 0회)       [§7 — 추가할 표면]
      → 2단 컨텍스트 주입 (LLM 소비, 산출물 층위)    [구현됨]
      → 3단 가중치 체화   (승격 (b)경로)             [미해결 — /lab, 세미나 표적]
```

- 접합은 어느 단이든 **산출물 층위**를 벗어나지 않는다. 기저 내부 표현
  (은닉 상태·로짓) 개입 금지 — 기저 교체 가능성이 전략 자산 (spec §3).
- 1단은 그 자체로 성립하는 서비스다(지식이 검색되어 사람에게 쓰임 = 시장의
  수요면 = 정산 역류의 측정 지점). 3단이 풀리는 동안 버티며 재료를 쌓는 트랙.

## 3. 검색-노출-석회화 회로 (v1.2 신규 — 검증자는 어디서 오는가)

**검증은 별도의 활동이 아니라 재사용의 부산물이다.** 검색으로 폴립을 만난
사람은 지금 그 주제가 필요하고, 자기 문제에 적용해보므로 판단할 맥락을 이미
갖고 있다. 판정단을 모집하는 것이 아니라 **검색 트래픽이 판정단을 실어 나른다**
(full-record §B3 "사용자 후속 반응 = 공짜 개입 데이터"의 구체적 통로).
이것이 v1.1 미해결 목록의 "참여 경제학(Aardvark 문제)"에 대한 구조적 답이다.

```
노출 (검색) → 판단 (찬성·반증·증분·실측) → 축적 → 석회화 판정
     ↑                                              │
     └────────── 정본이 재사용 가치를 높임 ←─────────┘
```

지켜야 할 경계 3개:

1. **노출 자체는 신호가 아니다.** 조회수·노출량이 석회화 조건에 스며드는 순간
   대리변수 금지가 무너진다. 노출은 판단의 **기회 공급**일 뿐, 판정에 들어가는
   것은 노출이 낳은 판단(스테이크·반증·실측)뿐이다.
2. **노출은 편향된다 — 분배 정책 필수.** 인기 주제만 노출되면 비인기 폴립은
   판단 기회 자체가 없어 영원히 계류한다(마태 효과). 검색 결과의 일정 비율
   (기본 30%)을 신규·잠복·저평가 풀에 강제 배정하는 **탐험 쿼터** 도입
   (H2A2H2 anti-Matthew 라우팅 이식 — "라우팅이 곧 기회이고 기회가 곧
   소득이면, 라우팅 분류기는 사실상 분배기다").
3. **첨삭은 덮어쓰기가 아니라 곁에 붙이기.** 원본 불변, 첨삭의 산물(교정·보강·
   반증)은 형제 노드가 되어 자신도 판단 대상이 된다. (dapsol 의 improve 가
   로그인만으로 남의 답변을 덮어쓸 수 있던 구멍의 반면교사.)

**잠복기의 재정의** [보간 — 산식 변경, 합의 대상]: 현 MVP 의 잠복기는 "관문
심사 횟수"라는 형식적 틱이다. 노출이 생기면 실질을 얻는다 — **"검색에 노출된
채 손상 없이 살아남은 기간"**. §B4 "시간이 검증자"가 이제 계산 가능해진다.

**폴립도 노출된다.** 검색 결과에 정본만 보여주면 폴립은 판단받을 기회가 없다.
폴립은 "미검증 후보" 표기와 함께 노출되고, 그 자리에서 바로 찬성/반증/증분이
가능해야 한다. **노출면이 곧 심사대다.**

## 3.5 누적 인정 정본화 — 특허 접지 (10-0913256 · 10-0952391)

석회화의 **양의 축**(인정의 축적)은 새로 발명할 것이 아니라 2005-04-14 동일자
출원된 두 등록특허(발명자 홍정수)가 이미 정의한 메커니즘이다.

**10-0913256 (기관 특허 — 순서 가중 누적 지수).** 청구항 1: 평가자(상위 노드)의
지수는 **링크한 순서**로 결정되고, 콘텐츠(하위 노드)의 중요도는 링커들의 지수
**합**으로 결정되며, **링크가 일어날 때마다 실시간 갱신**된다 (수렴 반복 없음 —
클라인버그 HITS 가 신규 콘텐츠를 실시간 평가 못하는 문제의 해법). 청구항 2·3:
이후 링커가 붙을 때마다 선행 링커의 지수가 증가(+1 또는 후속 링커 지수 합산).
→ **인정은 사건이 아니라 누적이다. 늦게 올라탄 자는 선행 발견자를 먹여 살린다.**
특허는 산출 변주 두 개를 명시한다 — 청구항 2(후속 링크마다 +1, 계수형) /
청구항 3(후속 링커의 지수를 합산, 지수 전파형) — 그리고 청구항 8 에
**평균 정규화**(허브 = 하위 노드별 지수들의 평균)를 둔다: 아무 데나 일찍
올라타는 산탄총 전략은 평균이 깎여 벌을 받는다. 안목은 재현율이 아니라
정밀도라는 것.

⚠ 이식 충실도 (`app/core/scoring.py` 실측): 현 구현은 특허 정신의 **제3 변주**다 —
① 선행 링커에게 후속 링커의 지수가 아니라 순위 감쇠 고정 가중(weight/j)을 더함
(청구항 2도 3도 아님; 감쇠는 특허에 없는 강화), ② 권위를 링크 시점 허브로
증분 고정 — 특허는 링크마다 기존 링커 허브와 하위 권위의 **재산출**을 명시
(늦게 입증된 안목이 소급 반영 안 됨), ③ 청구항 8 평균 정규화 부재 (산탄총
안목 방어 누락 — 이식 후보). 변주 자체는 허용이되 **어느 변주를 왜 쓰는지**를
scoring.py 상단 차이 기록에 남길 것 — 관문 지표가 되는 순간 산식은 공개
규약이다 (§1 "공개된 결정론적 함수").

**10-0952391 (시스템 특허 — 누적 인정의 두 소비처).**
- 청구항 6/14: **산출된 권위 지수에 따라 콘텐츠 노출이 조정된다** — §3 의
  검색-노출-석회화 회로가 이 청구항의 직계다.
- 청구항 7/15 + 명세: **허브(안목) 지수가 높은 사용자에게 편집자 기능**(카테고리별
  편집된 콘텐츠 제공, "개인 편집자") — 정본화 권한의 원형. 정본을 굳히는 자격은
  임명이 아니라 **입증된 안목의 누적**에서 나온다.

### 관문 설계에의 반영 (v1.3 변경)

1. **판정 ③단의 지표 교체**: 승격 문턱의 입력을 원시 스테이크 합이 아니라
   **누적 인정 지수(순서·허브 가중 권위)** 로 한다. 현 MVP 는 권위를 계산만 하고
   관문은 원시 스테이크 합을 본다 — 특허 기관이 장부 밖에 놀고 있는 상태.
   스테이크는 경제적 잠금(원장)으로 남고, 관문 지표는 권위가 맡는다.
   효과: 밴드왜건 내성(늦은 편승은 권위를 거의 못 올림) + 안목 가중(입증된
   평가자의 인정이 더 무겁다)이 관문에 내장된다.
2. **대리변수 오염 방지 조건**: 특허의 원 적용(추천·댓글)은 무비용 행위였다.
   coral 에서 링크로 세는 것은 **비용 있는 행위만** — 스테이킹·기여(증분·반증·
   실측). 무비용 클릭을 링크로 세는 순간 특허 기관이 대리변수(조회수류)로
   오염된다. [coral 의 강화 — 특허에 없는 제약]
3. **노출 회로의 근거 각주**: §3 의 "권위 가중 노출"은 청구항 6/14 의 구현.
   단 특허의 노출 루프는 순수 자기강화(권위↑→노출↑→평가↑→권위↑)라 마태
   효과를 내장한다 — coral 의 탐험 쿼터가 특허에 없는 보정이다. [차이 병기]
4. **편집권 로드맵**: 청구항 7/15 의 번역 — 정리·큐레이션 권한(H2A2H2
   organized_pages 형)을 허브 지수에 비례 부여. 로드맵 항목으로 §7 에 추가.
5. **링크 가중치는 항상 1.0** (구현 중 확정). 스테이크 액수를 링크 가중치로
   쓰면 관문 지표가 곧 지갑이 되어 tree.py 의 "포인트 크기 = 기여 크기"
   반(反)금권 규칙이 관문에서 뚫린다. 그래서 인정 지수는 **인정 1건당 약 1.0
   씩**(인정자의 안목만큼 가산) 쌓이고, 스테이크는 진입 비용·확신의 증거로
   병존하되 가중치를 사지 못한다. 관문이 세는 것은 액수가 아니라
   **누가 얼마나 일찍 알아봤는가**다. 그 결과 문턱 단위도 포인트가 아닌
   인정 건수이며 기본값은 3.0 이다 (25.0 은 구 스테이크 단위의 잔재였다).

### 특허와 coral 관문의 관계 (한 줄)

특허 = 석회화의 **양의 축**(누적 인정 + 노출 + 편집권). coral 관문 = 그 위에
**음의 축**(손상 판정·잠복 — 면역)과 **현실 축**(실측 닻)을 얹은 것. 판정
순서(§5)가 정확히 이 3축의 우선순위다: ①음 → ②현실 → ③양.

기재대로 해자는 적용 도메인으로 이동). 선행 지위와 계보 가치는 유효 — coral 의
"누적 인정 정본화"는 2005년에 확보된 발상의 직계임을 정본에 남긴다.

## 3.6 유발 설계 (elicitation) — 입력은 저절로 오지 않는다

사용자 정식화 (2026-08-20): "LLM 기저의 대화 과정에서 재치있게 온톨로지 입력을
사용자에게 **유발**하는 모든 기재를 동원해서, LLM 층과 별개로 **인간 가중치
기반 온톨로지 맵**을 구성한다." — 서비스 트랙의 제품 원리로 채택.

- **인간 가중치** = 비용 있는 인간 행위(스테이크·기여·순서) + 실측. 클릭·체류·
  조회는 절대 가중치에 넣지 않는다 (대리변수 금지).
- 유발 기재 재고 (전작 실증 포함): 검색 노출+그 자리 판단(D4) · **갭 역질문**
  (AI 가 답 끝에 되묻고 다음 답변을 자동 포획 — dapsol 실동작) · ⚠ challenged
  표기 · 증분 입력창 · "입증 책임은 당신에게" 반증 카피 · 에스크로 현상금
  (economy.py 보유, 미노출) · 탐험 쿼터 · AI 질문 생성+첫 답변 배수 ·
  허브 비례 편집권.
- 이로써 기저 LLM 의 정당한 역할 4종이 완결된다: ① 답변 생성 ② 구조화 추출
  ③ 충돌 제보 ④ **입력 유발**. 전부 산출물 층위, 전부 판정권 없음 — 유발은
  표를 주는 것이 아니라 사람의 입을 여는 것이다.
- 경계: **유발량 ≠ 가치** — 유발된 입력도 전부 관문을 통과한다 (유발이 늘수록
  관문이 먼저 서야 하는 이유가 강해진다). 유발 기재가 무비용 보상 낚시가 되는
  순간 유발 설계 스스로가 대리변수 제조기가 된다 — 좋은 유발은 보상이 아니라
  맥락의 자연스러움으로 연다.

## 4. 관문의 입력 — 사람의 행위 4종 + 기저 제보 1종

1. **반증** — 기존 노드를 편집·삭제하는 것이 아니라 **반증 주장을 담은 형제
   노드를 세우고** refutes 엣지로 대상을 겨눈다. 스테이크 필수(입증 책임).
   반증 노드 자체가 폴립으로 태어나 관문을 통과해야만 손상 효력을 갖는다 —
   "반증했다"가 아니라 **"반증이 검증됐다"가 손상**이다.
   UI 카피(H2A2H2 이식): "기존 답은 그대로 유지됩니다. 입증 책임은 당신에게
   있습니다."
2. **분기** — 모순 주장이 아니라 경쟁 답. relates_to(alternative) 엣지,
   스테이크 선택. 시스템은 답을 하나로 합치지 않는다 (reconcile 금지 —
   갈릴레오 보존).
3. **실측 닻** — 사람은 지표·기준값·관측값·임계만 입력하고 통과/미달/악화
   판정은 결정론 함수(`Measurement.passes`)가 낸다. v1.2 에서 **반증 대칭**
   추가: 악화(상대 개선 < 0)는 손상 신호다. 변화 없음·임계 미달은 "검증 안 됨"
   이지 반증이 아니다. [보간 — spec 은 검증 쪽만 명시했으므로 확장]
4. **스테이킹** — 기존대로. 반조작 규칙(자기투자·상호담합·쿨다운·워밍업·
   IP)은 dapsol `anti-gaming.ts` 의 검증된 세트를 이식.
5. **기저 제보 (판정 아님)** — 요청 시 기저 LLM 이 후보↔정본의 잠재 충돌을
   텍스트 플래그로만 남긴다. 판정 경로에 입력되지 않는다. 3중 방어: 스키마
   재파싱 + 참조 id 실존 검사(환각 방어) + 전체 로그 공개. 제보자가 죽어도
   관문은 그대로 돈다 — v0 의 fail-open 이 구조적으로 소멸.

## 5. 판정 함수 (순서가 설계)

```
① 손상 시험 → 잠복
     손상 = (a) 정본이 된 반증이 겨눈다  or  (b) 실측이 악화를 보였다
     스테이크 무관 — 자기 손상은 돈으로 못 이긴다
② 실측 검증 통과 → 승격  (실측 > 동의)
③ 누적 인정 미달 → 보류  (사유: recognition_below_threshold)
     지표 = 순서·허브 가중 권위 (특허 10-0913256 기관 — §3.5). 스테이크는
     경제적 잠금으로 병존하되 관문 지표는 권위다
④ 잠복기 미경과 → 보류      (사유: quarantine_pending)
⑤ 통과 → 승격
```

- **계류 반증은 승격을 차단하지 않는다** (v1 의 차단 규칙 삭제). 대신:
  - 계류 반증이 있는 노드는 승격 전후를 불문하고 "도전받음" 상태가 동행하고,
  - 주입·검색 노출 시 반드시 ⚠ 신호가 붙는다: "⚠ 반증 계류 중 (스테이크 N):
    {요지}" + "도전받은 지식은 불확실성을 언급하라" 지시 (dapsol 실동작 서식),
  - 반증이 관문을 통과하는 순간 대상을 **즉시 재심**한다 → ①(a)에 걸려 잠복.
    정본도 예외 없다 — "느리게 사는 층"의 구현.
- 트레이드오프 명시: 얻는 것 = 공짜 거부권 소멸, 현상 유지 편향 소멸(쿤 문제
  비악화), 모순의 공존. 내주는 것 = 반증이 검증되기 전까지 틀린 지식이 ⚠
  딱지를 달고 주입될 수 있음. 잠정 승격 + 가시적 도전 + 재심 가능이 차단 +
  방어 우위보다 이 시스템의 존재 이유(진리의 시간 비대칭성 보존)에 부합한다고
  판단. [세미나 승인 대기]
- 모든 거절·잠복에는 이유 enum 이 붙는다 (H2A2H2 gateReason 이식):
  `damaged_by_canonical_refuter / damaged_by_reality / stake_below_threshold /
  quarantine_pending` + 상태 플래그 `challenged`.

## 6. 감사 가능성 — 구현 규율 3 (전작 상처의 백신)

1. **판정 레코드에 입력 전문 보존** — 판정에 들어간 반증·실측·제보 전문,
   제보라면 모델 ID 까지. (dapsol: 판정 근거가 50자로 잘려 추적 불가)
2. **승인·반증은 인증된 행위자의 개별 레코드** — 개수를 세는 곳은 서버가
   레코드를 센다. (H2A2H2: 클라이언트가 타이핑한 이메일 배열의 길이로 정족수
   통과 가능)
3. **판정 결과는 반드시 상태를 바꾼다** — 계산만 하고 안 쓰는 게이트 금지.
   (dapsol: 붕괴 판정이 DB 에 안 남아 반증된 지식이 계속 주입됨 / H2A2H2:
   배당 계산 완비, 지급 함수 호출처 0)

| 표면 | 내용 |

| ask 2단 분리 | 1단: 검색 선점(정본+폴립, LLM 미호출) → 히트 제시. 2단: "부족함 — AI 에게 묻기"는 사용자의 명시적 행위 |

## 9. 미해결 (풀렸다고 주장하지 않는 것)

- 손상 판정 함수(§6-1): "검증된 반증의 존재"로 치환했을 뿐, 손상의 정도·자동
  판정은 미해결.
- 쿤 문제(§6-2): 차단 삭제로 악화는 면했으나, 반증이 관문을 통과하려면 결국
  스테이크나 실측이 필요하므로 보수성은 사람 시장 안에 남는다.
- 참여 경제학: §3(검색=판정단 공급)이 구조적 답이지만, 노출→판단 전환율은
  실측 전이다. 콜드스타트에서 관문은 여전히 스테이크+잠복기 위주로 돈다.
- 관문 적응 재귀(§6-3): 그대로.
