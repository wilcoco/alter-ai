## PART A. 이론적 기초 (왜 이 프로젝트인가)

### A1. AGI 연장선 논쟁
- 스케일링 진영: 능력 향상이 컴퓨트·데이터·RL 후처리에서 나왔고 천장 미관측.
  추론시간 컴퓨트·에이전트화가 새 축. (Anthropic/OpenAI 리더십)
- 불연속 진영(LeCun, Chollet): 아키텍처 수준 발명 필요. 근거 3결핍 —
  ① 지속 학습 부재 ② 세계모델의 언어통계 의존 ③ 샘플 비효율.
- 중간 판정: 경제적 인지노동 자동화까지는 연속 도달 가능성 높음. 그러나
  "적은 경험으로 새 도메인 학습"의 AGI는 지속학습·샘플효율이 미결.
- 정의 의존성: AGI 기준 = 경제적 대체 → 연장선 / 인간형 학습 → 갭.

### A2. 샘플 효율의 실체
- 인간 아이 10세까지 ~1억 단어 vs LLM 수조~수십조 토큰 (1만~10만 배).
- 아타리: 인간 15분 vs 초기 RL 수백만 프레임.
- 개념 형성: 아이는 기린 2-3장으로 견고한 범주, 모델은 수천 장 필요했음.
- few-shot 개선은 천문학적 사전학습의 결과 — 근본 해결 아님.
- 뇌는 20W로 적은 경험에서 인과 구조 추출. 현 체제는 물량 대체.
  인터넷 텍스트 유한 → 물량 전략의 천장이 스케일링 가설의 시험대.

### A3. 인과 추론 결핍 (Pearl 3층위)
- 관찰(1층)/개입(2층)/반사실(3층). 텍스트는 전부 1층.
- 모델은 자신이 개입해본 적 없음 → 상관에서 인과 식별 불가
  ("닭 울음과 해돋이" 구분 정보 부족).
- 텍스트 속 인간의 인과 분석을 검색해 읊는 것 ≠ 인과 추론 수행.
  훈련에 없는 새 시스템(예: 도장라인의 경화제 점도·라인속도·불량률)에선
  상관 패턴을 인과처럼 말하는 오류.
- 함의: 개입 루프(로봇·공장·사용자 상호작용)가 2층 데이터의 유일 원천.
  embodiment는 감각 추가가 아니라 **인과 학습의 필요조건**.

### A4. 불확실성 3층 구조
1. aleatoric(세계 자체): 데이터로 안 줄음.
2. epistemic(지식 부족): 개입 데이터로 감소.
3. **모사 불확실성**: 추론 수행 vs 추론 패턴 보간을 출력만으로 구분 불가.
   - 확신도(유창함)와 무상관 — 흉내일수록 더 단정적일 수 있음.
   - 1·2는 정량화 도구 있음(신뢰구간·베이지안), 3은 없음.
   - 실무 규칙: LLM 출력 = 가설 생성기, 검증 = 실제 개입(실험·A/B·공정조작).

### A5. "살아있음" 문제
- 현 사이클: 훈련→동결→배포→폐기 = 세대마다 처음부터 다시 만드는 조각상.
- 살아있는 지능 정의: 경험이 존재를 바꾸는 것 → 현 LLM 불통과.
- 30년 평가: 학습 규칙(역전파+경사하강, 1986)은 불변. 뇌는 역전파 안 씀
  (전역 오차 역방향 전파의 생물학적 기제 부재; Hinton도 말년에 재고,
  forward-forward 시도). 아키텍처/목표 수준은 진전(어텐션, self-supervised,
  RLHF) — 단 전부 고정 가중치 패러다임 내부.
- 인간 문헌 필터 의존: 부트스트랩 효율 최고 + 천장 상속(언어화 안 된
  암묵지·감각운동·언어 이전 인과 직관은 원리적으로 텍스트에 없음).
  AlphaGo→AlphaZero: 인간 기보 버리자 더 강해짐 — 단 닫힌 세계 한정.
- 스케일링이 올린 것 = 동결 지능의 성능. "살아있음" 축 진전 ≈ 0.

### A6. 파국적 망각의 해부
- 메커니즘: 지식은 서랍이 아니라 **수프** — 수십억 가중치에 분산 중첩,
  가중치 하나가 수천 능력에 기여. 경사하강은 현재 손실만 봄 → 과거 태스크에
  중요한 가중치를 제약 없이 덮어씀. **버그가 아니라 "분산 표현 + 현재만
  보는 최적화"의 논리적 귀결.**
- 과적합과의 관계: 사촌. 공유 뿌리 = 현재 분포 과적응. 차이 = 과적합은
  태스크 내 일반화 실패, 망각은 태스크 간 보존 실패. 과적합 없이도 망각
  발생 가능.
- 파인튜닝의 진짜 인과: 망각의 해결책이 아니라 **망각이 무서워 조금만
  움직이는 것.** 낮은 lr(1/100), LoRA(원가중치 동결+저랭크만), replay 혼합,
  KL 페널티 — 전부 "안 움직이기" 기법. 조금만 움직여야 한다는 사실 자체가
  지속학습 불가의 증거.
- 현 선택지 이분법: 크게 배우고 파국적으로 잊기(재훈련) vs 안 잊는 대신
  거의 안 배우기(파인튜닝). 제3모드(유기적 성장) 부재 = "살아있지 않음"의
  기술적 실체.
- 뇌의 해법: 해마(빠른 임시)-신피질(느린 통합) + 수면 중 재생(신구 혼합
  재생으로 통합) = CLS 이론 (McClelland, McNaughton & O'Reilly 1995).
  단일 시스템으로는 딜레마 못 푼다는 계산적 필연성 논증.

### A7. 뇌형 구조의 실증 단서
- 수상돌기 = 뉴런 내 국소 비선형 서브유닛 (생물 뉴런 1개 ≈ 인공 뉴런
  수백 개 심층망, 2021 연구). Numenta active dendrites: 문맥 신호가
  태스크별로 뉴런 부분집합 활성화 → 망각 완화 실증.
- MoE: 구획은 있으나 추론 효율용. 훈련은 여전히 전체 경사하강.
  전문가 분화는 창발적·토큰 통계 기준 — 지속학습에 안 쓰임.
- 뇌의 완전한 재료: 구획 + **가소성 게이팅**(신경조절물질의 국소 학습률
  실시간 제어 — 도파민·아세틸콜린) + 희소 활성화(1-2%만 발화 → 간섭 최소)
  + 이중 속도. **정적 구획만으로는 부족, "언제 어디를 말랑하게"의
  게이팅·조절 시스템이 필수.**

## PART B. 비전과 전략 (무엇을 지을 것인가)

### B1. 비전 선언과 확정 과정
- 사용자 원 선언: "노드 늘려 경사하강·역전파 — 이 틀에서 벗어난 것이 없다.
  신경망 구조와 최적화의 다른 대안을 만들려는 것. 거대한 과제다."
- Claude의 지형 브리핑: 대안 학습규칙 실패사 — Forward-Forward(Hinton
  2022, 스케일에서 패), Equilibrium Propagation(수렴 느림), Predictive
  Coding(역전파 근사임이 증명 → "왜 굳이"), Hebbian/STDP(뉴로모픽에
  생존, 성능 격차). **공통 사인 = 신용 할당의 정확도·속도에서 역전파에
  패배 + GPU/CUDA 생태계의 하드웨어 우연이 이중 부담.**
- Claude 중력 1차: "정면 대체 아닌 침투(하이브리드)"로 재정의 시도 →
  **사용자 기각** ("우리 접근은 아예 구조적 대안 제시다").
- 역전파 평가의 균형: 역전파의 승리는 "정적 데이터 일회 훈련" 게임 규칙
  하의 승리. 게임을 지속학습으로 바꾸면 왕좌의 기반(전역 경사하강)이
  곧 약점.

### B2. 다섯 명세 (모든 학습 시스템의 채점 기준)
1. 신용 할당 — 오차/보상 책임 배분 방법
2. 지식의 기질 — 저장 위치·형태 (이 선택이 망각·조합·해석성 결정)
3. 안정성-가소성 중재 — 굳힘/열림의 결정 주체
4. 시간의 취급 — 스트림 일급 vs 셔플 뭉개기
5. 스케일 경로 — 10⁶→10¹² (대안들의 공동묘지)

### B3. 구조 대안: 배포 후 사용자 입력 학습
- 장벽 3종: ① 망각/간섭 — 사용자 스트림은 비정상·상관·순차 = 망각 최악
  조건. 루프 변경은 필요조건일 뿐. ② 오염 — 학습이 열리면 사용자=훈련자.
  Tay(2016) 16시간 붕괴. 살아있는 시스템은 감염됨 → 면역계는 생명의 세금.
  ③ 평가/회귀 — 동결은 기술 무능만이 아니라 책임 구조의 산물.
- 구조 삼분: A) 단일 전역(Tay형, 최대 노출) B) 사용자별 격리(오염 국소화,
  집단 성장 없음) C) 계층 — 개인 빠른 학습 → 검증 관문 → 전역 느린 통합
  = **CLS의 시스템 수준 재연.**
- 숨은 자산: 사용자 후속 반응(수정·만족·이탈) = 공짜 개입(2층) 데이터
  = 약한 보상 신호로 신용 할당 일부를 환경이 대신 풂.

### B4. 면역계 설계 (사용자 제안: "격리해서 면역 통과 로직")
- 재해석: 삼분법 C의 선택이 아니라 **관문을 시스템의 심장으로 격상.**
- 성립하는 면역학 번역:
  - danger model(Matzinger): 자기/비자기 아닌 **위험/손상** 기준.
    → 관문 질문 = "낯선가"(novelty)가 아니라 "통합하면 손상되는가".
    낯섦은 오히려 학습 가치.
  - 음성 선택: T세포 흉선 시험 → 업데이트 후보를 보호 능력 검증셋에
    시험 발사, 손상 시 기각. **망각 방지와 오염 방어가 동일 메커니즘**
    (둘 다 "기존 자기의 손상").
  - 격리층 = 국소 봉쇄(오염 반경 제한) + 잠복기 관찰(N일 개인층 운용 후
    통합 심사 — 시간이 검증자).
- 깨지는 부분 = 미해결 스택:
  1. 손상 판정 함수 [실험 가능]
  2. 음성 선택의 보수성 — 패러다임 전환 지식은 기존 검증셋과 충돌 →
     구조적 기각 (쿤 문제)
  3. 관문의 적응 학습 재귀 — 적(경제적 게이머·오염자)은 인간 지능으로
     리버스엔지니어링 → 정적 관문은 반드시 뚫림 → 관문도 학습해야 →
     그 학습 신호는 누가 검증? (생체의 답 "개체 죽음+종 선택"은 사용 불가)
  4. **자기(self)의 계산적 정의** — 음성 선택은 자기 항원 목록 필요.
     능력 벤치마크는 자기의 그림자일 뿐. 생체는 게놈이 줌, 우리는 만들어야.

### B5. 학습 대상 결정의 시스템화 (사용자 통찰)
- 통찰: "학습 대상 설정·과정이 독점적. 머티리얼도 사람이 만든 것. 이걸
  시스템화한다는 것."
- 재인식: **현 체제에도 면역계 존재 — 랩 내부 인간 편집 노동(데이터
  큐레이션·어노테이션 지침·RLHF 라벨러)으로 은폐.** 데이터 파이프라인이
  사실상의 흉선.
- 우리 과제 = 은폐된 편집 판단의 외재화 + 결정권 분산 = 기술 설계이자
  **거버넌스 설계.**
- 실증 참조: 위키피디아(롤백=손상판정, 감시목록=잠복관찰, 신뢰계층=격리,
  토론합의=관문 적응) · 리눅스 커널(메인테이너 위계 = 신뢰 그라데이션).
  과제 재표현: "위키피디아 편집 거버넌스에서 인간 판정을 어디까지 계산
  가능 함수로 대체할 수 있는가."
- 인간 의존의 질적 전환: 정적 문헌(1층 관찰) → 상호작용 루프(2층 개입
  데이터 흐름).

### B6. 지식 시장 (사용자 제안: "동기 — 유튜브형 수익 배분")
- 위키 모델 한계: 무보수로는 희소 전문지식(기회비용 높음) 동원 불가 →
  시장 필요.
- 지형: Scale AI(시간 매입, 기여 비례 아님) · Data Shapley(Ghorbani & Zou
  2019 — 이론적 기초, 계산 조합폭발) · 크립토 데이터마켓(수요 부재 공회전).
- 핵심 난제 = **귀속.** 유튜브는 조회수=콘텐츠 단위 장부. 신경망은 분산
  중첩 → "수프에 녹은 소금값 정산" 불가.
- 수렴 신호: 격리층(기여 단위 모듈)이 면역·망각·**정산**을 동시 해결
  (모듈 단위 호출·가치 계측 가능).

### B7. 게이밍 논쟁 → 유인합치 (사용자 반박이 프레임 교정)
- Claude 초기 프레임: 게이밍 = 시장의 병리, 방어 기술 필요 (애드센스
  무효클릭 탐지 유추).
- 사용자 반박: "게이밍이 문제면 시장 자체의 한계 아닌가" → **정확.**
- 교정된 프레임 (메커니즘 디자인): 게이밍 가능 = 가격 신호와 진짜 가치의
  괴리 증거. 유인합치(incentive compatibility, Hurwicz-Maskin-Myerson
  2007 노벨상)에서는 정직 기여가 최적 전략 → 게이밍 범주 소멸.
  유튜브 낚시썸네일 = 주의(조악한 대리변수)를 가격으로 쓴 설계 귀결이지
  크리에이터 타락이 아님. 방어 기술 = 잘못된 가격 신호 유지 비용.
- 지식 시장의 구조적 이점: 기여 가치가 **사후 실측됨**(통합 후 성능 개선)
  → 지연된 진짜 신호 존재 → 예측시장 동형 (기여 시점 추정가 → 실측 후
  정산 보정; Hanson LMSR 참조 예정).
- 한계 명시: 불가능성 정리(Myerson-Satterthwaite — 효율·정직·예산균형
  동시 불가) → 목표 = 게이밍 소멸이 아니라 **정직 기여 기대수익의 구조적
  압도.**
- 통합 인식: 관문의 손상 판정 = 시장의 가치 산정 = **"지연 실측 신호를
  적대 환경에서 현재 판정으로 번역하는 함수"의 두 얼굴.**

## PART C. 자산 통합과 아키텍처 확정

### C1. CAMS-KnowledgeNet 대조
- 실체: 온톨로지 기반 지식 평가·보상 시스템. 특허 10-0913256/10-0952391
  (허브-권위 링크그래프, 2005, 만료→공공영역, 해자는 적용 도메인으로 이동).
- 4층 스택 대응: scoring.py(안목=선행발견 보상 — 예측시장 동형) ·
  verification.py(외부 현실 닻 — 배당은 검증 가지에서만; "부가가치=동의"
  순환을 제조 ground truth로 폐쇄) · 스테이킹/에스크로(경제적 면역) ·
  governance.py(N명 시 자동 분권) · economy.py(닫힌 포인트, UBI, 시간붕괴,
  잠복 회수).
- 심층 발견: 명세 2(기질)에 정반대 답 — **이산 노드(서랍) vs 분산
  중첩(수프).** 연쇄 해소: 정산(귀속 자명) · 망각(잠복/부활, 덮어쓰기
  없음) · 자기 정의(보호 대상 = 검증된 온톨로지).
- 한계: 망각을 푸는 게 아니라 **우회.** 모델 동결 유지. 남는 문제 —
  온톨로지→능력 경로(RAG는 임시 메모리 한계 상속) · **암묵지 병목**
  (자체 시뮬레이션 실증: "카토의 손끝 지식 끝내 안 풀림").
- 지식층/능력층 구분 확립: 온톨로지는 살아있음(노드 성장), 가중치는 동결.
  RAG 한계 3: 읽기≠능력(조합·전이 약함 — 컨텍스트 지식은 명시 호출
  필요, 가중치 지식은 모든 추론에 자동 침투) · 검색 병목(검색기는 모델만큼
  관련성 이해 못함) · 노드 횡단 암묵 패턴 비전달.

### C2. 전략 확정 (중력 2건 경유)
- 중력 3: Claude가 기존 사전학습 모델 몸체 전제(어댑터/주기 통합)로 회귀
  → 사용자 교정 "기존 학습 구조·기존 모델을 쓰는 것이 아닌 것을 지향".
- 중력 4(과교정): Claude가 백지 출발로 해석 → 부트스트랩 문제(언어 능력
  원천) 제기 → 사용자 재교정.
- **최종 전략**: "기존 LLM을 활용해서 그 윗단에 별개의 신경망(사용자
  참여형)이 얹어지는 형태."
  - 동결 기저 = 언어·상식·추론 기질. 부트스트랩 해소(기저가 세금 냄).
  - 자기 문제 축소(기저는 동결로 원천 보호 — 손상 판정은 상부만).
  - 대안 학습규칙의 현실 전장(상부망은 작음 → 비역전파 규칙 투입 가능).
  - 핵심 정식화(사용자): **"LLM 소스는 스케일 경쟁 대상. 그 베이스에서
    기본 문답 처리. 모자란 부분이 우리 별개 신경망에 누적."**
    → 전략 원칙: 스케일은 남의 전쟁, 우리는 그 위에 누적되는 것을 소유.
    기저 교체 가능(GPT/Claude/오픈웨이트 무관), 우리 자산(상부망+온톨로지)
    은 생존. 성장 축 = 컴퓨트 → 검증 지식 축적 속도.

### C3. 접합 문제와 해소
- Claude 초기 삼분류: 텍스트 층위(학습하는 검색기로 퇴행 위험) / 표현
  층위(은닉 상태 조향 — 체화 최근접, 기저 종속 발생) / 출력 층위(로짓
  변조, kNN-LM류).
- 트레이드오프 경고: 교체 가능성 vs 접합 깊이.
- 사용자 해소: "인간 질문 → LLM 대답 → 가치 증분 or 그대로 채택 (문답
  소유자=사용자)" → **산출물 층위 접합 = 기저 완전 독립.** 경고 철회.
  내부 표현 접합은 후순위 최적화 옵션. 남는 문제 = **라우팅**(기저 답
  채택 vs 상부 개입 판별).

### C4. H2A2H2 통합
- 실체: 3-패널 지식 에디터 (Next.js). 우: AI 문답 → 촘스키 P→I→C
  (전제→추론→결론) 자동 개념화 → Auto-apply / 중: 승인된 지식그래프
  (노드: concept·claim·evidence·source·qa·premise·inference·conclusion;
  엣지: supports·refutes·relates_to·cites·infers; ±1 투자) / 좌: 발행된
  works 키워드 발견. ADR-0001: "지식을 텍스트가 아니라 규칙/구조로 포획."
- 위치: **3-레포 파이프라인의 최상류.** H2A2H2(대화→구조 포획, 증발 방지)
  → KnowledgeNet(검증·가격·배당) → 가소성 층(체화, 미해결).
- 핵심 수확: **상부망 훈련 신호 가설 — "다음 토큰"이 아니라 검증된 추론
  그래프.** 평평한 텍스트=관찰 데이터, P→I→C=추론 구조 자체의 데이터
  (Pearl 층위 상승). + 검증 강도 = 인공 신경조절물질(가소성 게이팅) 가설.
- 한계(§4): 절차적·감각적 지식은 명제 구조에 안 담김 — 암묵지 병목이
  포획 단계에서도 재등장.
- 메타: 이 대화 자체가 H2A2H2 사용 사례 (맥락 저장 요청 → 수동 세션 로그
  = H2A2H2가 자동화하려는 흐름).

### C5. 산호초 모델 (정본 은유 — 사용자 반전)
- Claude 초기 매핑: 폴립=LLM 문답(일시), 골격=우리 축적층. 생태 유사
  후보: 산호초 / 토양(분해자=면역) / 과학 문헌(피어리뷰=관문) / niche
  construction.
- **사용자 반전 (채택)**: "기존 LLM이 안정층. 그 위에 우리 폴립이 붙어서
  우리 로직으로 안정화되면 안정층으로 승격."
  - 기저 LLM = 기존 안정층 = 인류 문헌의 석회화 (두꺼움, 동결).
  - 우리 시스템 = 폴립층 = 죽은 초 표면의 활성면 (얇음).
  - 성장 = 활성층의 안정층 **승격** (산호초의 실제 성장 방식).
- 승격 3경로: (a) 온톨로지 정본에 굳음 (b) 상부망 가중치 체화
  (c) 장기: 차세대 기저 LLM 훈련 데이터 편입 → 문명 규모 루프 폐쇄.
- 검증 닻 + 시장 + 관문 = 하나의 **석회화 판정 기관** (통합 재인식).
- 설계 교훈: 세 유사물 모두 활성층 얇고 안정층 두꺼움 → 자원 배분 힌트.
- 은유 한계: 우리 안정층은 재평가·잠복·부활 — "느리게 사는 층" (CLS
  이중속도와 재접속). 4중 수렴(산호초/토양/문헌/CLS) = 설계 방향 신호.

### C6. 방향 종합 (최종)
한 문장: **인간-AI 대화에서 태어나는 지식을 구조로 포획하고, 시장으로
검증하고, 신경망으로 체화시키는 살아있는 집단 학습 시스템.**
루프: 포획(H2A2H2) → 검증·가격(KnowledgeNet) → 체화(가소성층, 미해결)
→ 환류(실측 기여도 배당).
뒤집는 세 독점: 학습 시점(동결→지속) · 학습 대상(랩 은폐 큐레이션→시장
+검증+거버넌스) · 가치(데이터 무상 수취→기여 정산).
AGI 논쟁 좌표: 스케일링(더 큰 동결 지능)이 아니라 "살아있음" 축 베팅.

## PART D. 세미나 (이론 트랙)

### D1. 커리큘럼 (확정)
1. 안정성-가소성 딜레마 ← **1강 완료, 되말하기 숙제 미제출**
2. 경사하강+분산표현의 간섭 수학 (loss landscape 곡률·Mirzadeh 2020,
   그래디언트 간섭·GEM Lopez-Paz & Ranzato 2017, EWC Fisher 근사와 실패)
3. 표현 이론: 중첩·polysemanticity (Elhage et al. Toy Models of
   Superposition) + pseudo-forgetting 논쟁
4. 생물학적 해법 계산 이론 (CLS, 시냅스 통합, 신경조절 게이팅, 희소 코딩)
5. 해법 분류학과 실패 양상 (LLM CL 서베이: Shi et al. 2404.16789)
- 역할: 지속학습 공부가 아니라 **현 체제 부검** — 무엇이 필연이고 무엇이
  역사적 우연인지 (특히 역전파 승리 중 GPU 생태계 우연의 몫).
- 병행: 세션 3부터 이해 도구용 소실험(작은 MLP 순차학습 관찰) 허용.

### D2. 세션 1 내용 (완료분)
- Grossberg 정식화: 가소성과 안정성은 같은 손잡이(변화 감수성)의 양끝 —
  별개 기능 최적화가 아니라 하나의 변수 위 정면 충돌 = 딜레마.
- 딜레마 성립 3전제: (i) 표현 공유 (ii) 학습 신호가 현재만 봄
  (iii) 과거 재접근 불가. 셋 성립 시 침식은 정리 수준.
- **완화책 삼분류 = 3전제의 논리적 전수조사**: (i) 격파→모듈화·희소화
  (일반화 대가) / (ii) 격파→정규화·EWC (학습 정지 대가) / (iii) 격파→
  replay (전체 재훈련 수렴 대가). 전부 완화인 이유 = 전제 제거가 아닌 약화.
- ART (Grossberg의 답): 입력→기존 범주와 공명 판정(vigilance)→익숙하면
  해당 범주만 갱신, 낯설면 새 노드 할당. "굳은 것 보호, 새것은 새 자리"
  = 승격·격리의 원형. 실패 이유: 국소 표현(일반화 포기)·vigilance 조악·
  스케일 실패 — 단 원리가 아니라 표현력 교환에서 진 것.
- 현 체제 판정: 딜레마를 푼 게 아니라 **시간 분리로 회피** — 훈련 중
  i.i.d. 셔플(전제 iii 부정 = 가소성 전부), 배포 후 동결(안정성 전부).
  i.i.d.는 수학적 요구에 가까움(확신도 높음), 동결은 제도적 선택.
  "동결 필연" 착시 = 원리 강제와 제도 선택의 혼동.
- 우리 시스템 좌표: 층마다 딜레마의 다른 지점 배정 — 기저(안정 100%) /
  상부망(가소 우위, 격리+검증 게이팅) / 온톨로지(명시 판정으로 굳음).
  ART의 vigilance 스칼라를 석회화 판정 기관 전체로 교체하는 시도로 독해
  가능 (Claude 매핑 — §3 점검 대상).
- 세션 1 저확신 목록: ① "i.i.d.=수학적 요구" 표현 과함 가능(표준 가정이
  정확) ② Grossberg 연대·문구는 재구성 ③ ART 실패 원인 비중은 역사 해석.
- **미제출 숙제**: 3전제-완화책 대응을 사용자 언어(사출/도장 비유)로
  재구성 → 우리 시스템이 어느 전제를 어떻게 깨는지 도출.

## PART E. 진행 규약과 메타

### E1. 검증 프로토콜 (verification-protocol.md 요약)
5축: 출처(합의/보간) · 확신도 분리 · 중력 방지 · 되말하기 · 수식 검증.
운영: 세션당 3회+ 발동, 인용 시 제목·저자·연도 요구, 모순 시 추궁,
분류당하면 §3 발동, 말미 저확신 목록.

### E2. Claude 중력 기록 (경계 목록 — 누적 4건, 전부 사용자 기각)
1. 비전을 하이브리드/침투로 축소
2. 전역 시스템을 CAMS 사내 규모로 축소
3. 기존 사전학습 모델 몸체 전제(RAG+/어댑터)로 회귀
4. (과교정) 백지 출발로 해석
패턴: 기존 지형에서 생존 확률 높은 쪽으로 끌어내리는 경향 + 반동 과교정.
사용자 아이디어의 기존 범주 분류("그건 X랑 비슷") 시 차이점 필수 점검.

### E3. AI 협업의 인식론 (합의)
- Claude 지식 = 정본 지도의 큐레이션. 중력 실재. 조합 신규성은 가능
  (훈련 분포에 없는 교차점 — 예: 신경조절 게이팅 × 공정 드리프트 ×
  지식 외재화).
- 분업: 출발(departure)=사용자 / 검증·맥락화=Claude.
  Claude의 "이상한데요"는 훈련 분포 이탈 신호일 수 있음 — 흥미 신호.
- 저장/학습 맥락: 소비자 대화는 설정 따라 학습 사용 가능(5년 비식별 보관),
  개별 아이디어 마이닝은 인센티브 상 비현실, 집계 패턴이 로드맵 되는
  구조(아마존 PB 유추)가 실제 리스크. 발견되려면 공개 퍼블리시가 경로
