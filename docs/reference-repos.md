# 참조 레포 정독 요약 (2026-08-20)

> QAQA · dapsol · H2A2H2 · human-node 4개 레포 전수 정독의 압축본.
> 목적: coral 설계(특히 승격 관문 v1.2)의 실증 근거 보존.
> 전문 보고서는 세션 기록에 있으며, 여기엔 설계에 흡수된 결론만 남긴다.

## 0. 각 레포의 실체 (문서 아닌 코드 기준)

| 레포 | 실체 | 상태 |
|---|---|---|
| **H2A2H2** | 두 겹. v1 "P→I→C 그래프 편집기"(coral 이 스키마를 이식한 원본)는 **폐기된 죽은 코드**. 실동작은 v2 "nightwish Q&A 온톨로지" — 검증 닻·스테이킹·잠복/부활·포크가 Postgres 위에서 동작 | 인프라 실동작, 배당 지급·자동 분권 등 마지막 배선 누락 |
| **QAQA** | AI 문답을 영토 삼아 발자국으로 경작(찬성)/사냥(반증)하고, 검증 신호를 달아 다음 대화에 재주입하는 Next.js 앱 | 백엔드 정교, 문서·테스트·어휘가 코드에 뒤처짐 |
| **dapsol** | QAQA 의 포크 + "AI 빈틈 사냥" 리포지셔닝. 원 비전(답설/LTN·ZKP)은 코드 0줄 | QAQA 동일 계열 |
| **human-node** | 사람이 노드. 지식이 아니라 "누가 아는가"의 주소(지명 링크)만 저장, 요청이 링크를 타고 라우팅, 채택이 가중치 보강 | 전 루프 테스트 통과 소형 MVP |

## 1. 최대 발견: 수렴 진화 — 관문 실험이 이미 두 번 돌았다

- **H2A2H2**: v1 의 명시 결정은 "LLM 패치 자동 적용(Auto-apply)" (ADR-0001).
  **v2 에서 스스로 뒤집음** — LLM 은 제안만(bookkeep, 항목별 개별 승인), 승격급
  판정은 사람이 입력한 실측치에 대한 결정론 함수. 다이얼로그 카피:
  *"동의·만족도는 닻이 아닙니다."*
- **dapsol/QAQA**: 반대 방향 — LLM 이 기여의 정확도·중요도를 채점하고 **시스템
  계정이 실제 포인트를 발행** (`opinions/evaluate`). 파싱 실패 시
  `{isValid:true}` 로 **fail-open**. 자기 원 문서의 원칙("AI는 판사가 아니라
  경비견")과 배치된 채 방치 → **중력 5(coral v0 관문)와 동일 병의 독립 재발.**
- **human-node**: "전부 사람" 극단의 대조군. LLM 이 코드에 없음. 대가(판정자
  소진·초기 신호 부재)를 자기 문서가 Aardvark 사망 사례로 명시.

→ coral 관문 v1.2 원칙("사람은 증거, 판정은 공개 함수, 기저는 제보자")의 실증 근거.

## 2. 불변 코어 루프 (다섯 코드베이스 공통)

"묻는다 → 기존 대화 저비용 검색 → 부족하면 AI → 찬성/반대/추가/공유"는 모든
피벗을 살아남은 유일한 구조. H2A2H2 v1 은 검색 히트 시 LLM 호출을 중단하고,
v2 는 동일 질문(유사도>0.6) 존재 시 `reused:true` 로 쿼터 미차감 반환.
human-node 는 3단계에서 AI 대신 사람에게 라우팅하는 변주.

## 4. 복제 금지 목록 (전작의 상처 → coral 구현 규율)

1. **LLM 이 화폐를 발행** (dapsol evaluate) — 중력 5의 완성형.
2. **fail-open** — LLM 죽으면 통과. 관문은 fail-closed.
3. **판정이 상태로 안 남음** — dapsol 붕괴 판정은 계산만 되고 DB 미기록 →
   반증된 지식이 계속 주입됨. 검증과 주입의 분리 금지.
4. **정본 승격이 작성자 자기신고** — 게이트 없는 canonical.
5. **승인 정족수를 길이로 셈** — H2A2H2 거버넌스: 클라이언트가 타이핑한 이메일
   배열 길이로 통과. 승인은 인증 세션의 개별 레코드로.
6. **루프의 마지막 한 줄 미배선** — H2A2H2 배당: 계산 완비, 지급 함수 호출처 0.
7. **어휘 분열** — 반증 사유가 한 레포 안에 3벌. 단일 어휘 레지스트리로 시작.
8. **문서-코드 드리프트** — 폐기한 버전의 문서를 지우지 않아 새 참여자에게
   잘못된 지도를 줌. (H2A2H2 ADR-0001 의 Auto-apply 는 그 레포에서 이미 폐기된
   결정임을 여기 명시해 둔다 — coral 이 이식한 스키마의 출처 문서라서.)
