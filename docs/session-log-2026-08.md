## 0. 프로젝트 정체성 (한 문단)

현행 AI 체제(역전파 + 전역 경사하강 + 동결-배포-폐기)에 대한 **구조적 대안**을
설계한다. 침투/하이브리드가 아니라 학습 시스템 차원의 대안이 목표. 접근은
이론 선행(문제의 일급 이해) 후 설계. 기존 자산 CAMS-KnowledgeNet(지식 시장·
검증 닻·거버넌스)이 시스템의 바깥층, 신경망 가소성 메커니즘이 미해결 심장부.

## 1. 논증 사슬 (도달 순서대로)

### 1.1 출발: AGI는 현 발전의 연장선인가
- 스케일링 진영 vs 불연속 필요 진영. 미해결.
- 현 LLM의 구조적 결핍 3개: **지속 학습 부재 / 세계모델의 언어통계 의존 /
  샘플 비효율**.
- 정의 문제: AGI 기준을 "경제적 대체"로 잡으면 연장선, "인간형 학습"으로
  잡으면 갭 존재.

### 1.2 샘플 효율
- 인간 아이 ~1억 단어 vs LLM 수조 토큰. few-shot 능력은 천문학적 사전학습의
  결과이지 근본 해결 아님.
- 뇌는 20W로 적은 경험에서 인과 구조를 추출. 현 아키텍처는 물량으로 대체.

### 1.3 인과 추론이 약한 이유 (Pearl 3층위)
- 관찰 / 개입 / 반사실. 텍스트는 전부 1층(관찰) 데이터.
- LLM은 인과 추론을 수행하는 게 아니라 인과 지식을 검색. 훈련 데이터에 없는
  새 시스템에서는 상관을 인과처럼 말함.
- 개입 루프(로봇, 공장, 사용자 상호작용)가 2층 데이터의 유일한 원천.

### 1.4 불확실성 3층
1. 세계 자체(aleatoric) — 줄일 수 없음
2. 지식 부족(epistemic) — 개입 데이터로 감소
3. **모사 불확실성** — 추론인지 흉내인지 출력만으로 구분 불가. 확신도와 무상관.
   정량화 도구 부재. → LLM 출력은 가설 생성기로, 검증은 실제 개입으로.

### 1.5 살아있음의 조건
- 현 체제: 훈련→동결→배포→폐기. "경험이 존재를 바꾸는" 학습이 없음.
- 30년 평가: 학습 규칙(역전파+경사하강, 1986)은 불변. 아키텍처(어텐션,
  self-supervised, RLHF)는 진전. 단 전부 "고정 가중치 패러다임 안"의 진전.
- 스케일링이 올린 것은 "동결된 지능의 성능"이지 "살아있음"이 아님. 그 축의
  진전은 ~0.

### 1.6 파국적 망각의 구조
- 원인 = **분산 중첩 표현 + 현재 데이터만 보는 최적화**의 논리적 귀결.
  버그가 아님.
- 지식은 서랍이 아니라 수프. 가중치 하나가 수천 능력에 동시 기여.
- 과적합과의 관계: 사촌. 과적합=일반화 실패(태스크 내), 망각=보존 실패
  (태스크 간).
- 파인튜닝의 인과: 망각의 해결책이 아니라 망각이 무서워 조금만 움직이는 것
  (낮은 lr, LoRA, replay, KL 페널티 = 전부 "안 움직이기" 기법).
- 현 선택지 둘뿐: 크게 배우고 파국적으로 잊거나(재훈련) / 안 잊는 대신 거의
  안 배우거나(파인튜닝). 세 번째 모드(유기적 성장)가 없음 = "살아있지 않음"의
  기술적 실체.
- 뇌의 해법: 해마(빠른 임시)-신피질(느린 통합) 이중 시스템 + 수면 중 재생
  (CLS 이론, McClelland et al. 1995).

### 1.7 뇌형 구조 방향 (가능성 확인)
- 수상돌기 = 뉴런 내 다단계 서브유닛. Numenta active dendrites: 태스크별로
  뉴런의 다른 부분집합 활성화 → 망각 완화 실증.
- MoE는 구획이 있으나 추론 효율용. 지속 학습에 안 쓰임.
- 뇌의 진짜 비결 = 구획 + **가소성 게이팅**(신경조절물질의 국소 학습률 제어)
  + 희소 활성화 + 이중 속도. 구획만으로는 부족.

### 1.8 비전 확정
- "역전파는 그 세팅(정적 데이터 일회 훈련)의 승자일 뿐. 우리는 구조적 대안."
- 대안 학습규칙 실패사: Forward-Forward, Equilibrium Propagation,
  Predictive Coding, Hebbian/STDP. 공통 사인 = 신용 할당의 정확도/속도에서
  역전파에 패배 + GPU 생태계의 하드웨어 우연.
- 재정의 제안(하이브리드/침투)은 사용자가 기각 → 큰 판 유지.

### 1.9 다섯 명세 (모든 학습 시스템의 필수 답변)
1. **신용 할당** — 오차/보상 책임을 어떻게 배분하나
2. **지식의 기질** — 배운 것이 어디에 어떤 형태로 저장되나
3. **안정성-가소성 중재** — 언제 굳히고 언제 여는지 누가 결정하나
4. **시간의 취급** — 경험 스트림을 일급으로 다루나, 셔플 배치로 뭉개나
5. **스케일 경로** — 10⁶→10¹² 가는 길이 있나 (대안들의 공동묘지)

### 1.10 구조 대안 1: 배포 후 사용자 입력 학습
- 장벽 3: 망각/간섭(루프 변경은 필요조건일 뿐) · 오염(Tay 사례; 살아있는
  시스템은 감염됨 → 면역계 필요) · 평가/회귀(동결은 책임 구조의 산물이기도).
- 구조 삼분: (A) 단일 전역 모델 (B) 사용자별 격리 (C) 계층(개인 빠른 학습 →
  검증 관문 → 전역 느린 통합 = CLS의 시스템 수준 재연).
- 숨은 자산: 사용자 피드백 = 공짜 개입(2층) 데이터.

### 1.11 면역계 설계 (사용자 제안: 격리 + 면역 통과 로직)
- 관문을 부속품이 아니라 시스템의 심장으로.
- 성립하는 번역: danger model(novelty 아닌 **손상** 기준 판정) · 음성 선택
  (보호 능력 검증셋에 시험 발사, 손상 업데이트 기각 — 망각 방지와 오염 방어가
  동일 메커니즘) · 격리층 = 국소 봉쇄 + 잠복기 관찰.
- 미해결 스택(아래로 갈수록 깊음):
  (1) 손상 판정 함수 — 구현 가능성 보임
  (2) 음성 선택 관문 — 가능하나 보수성 편향(쿤 문제: 패러다임 전환 지식을
      구조적으로 기각)
  (3) 관문의 적응 학습 — 재귀 문제(관문 학습 신호는 누가 검증?)
  (4) **자기(self)의 계산적 정의** — 가장 깊음. 생체는 게놈이 줌, 우리는
      만들어야 함.

### 1.12 학습 대상 결정의 시스템화 (사용자 통찰)
- 현 체제에도 면역계는 있음 — 랩 내부의 인간 편집 노동(데이터 큐레이션,
  어노테이션 지침)으로 **은폐**되어 있을 뿐.
- 우리 과제 = 그 은폐된 편집 판단의 외재화 + 결정권의 분산.
- 참조 실증: 위키피디아(롤백/감시목록/신뢰계층/토론합의), 리눅스 커널
  (메인테이너 위계). 인간 판정을 어디까지 계산 가능한 함수로 대체하는가의 문제.
- 인간 의존은 소멸이 아니라 질적 전환: 관찰(1층) 의존 → 개입(2층) 데이터 흐름.

### 1.13 지식 시장 (사용자 제안: 유튜브형 수익 배분)
- 위키피디아 모델의 한계: 무보수로는 희소 전문지식 동원 불가 → 시장 필요.
- 핵심 난제 = 귀속(attribution). 유튜브는 콘텐츠 단위 계측이 가능하지만
  신경망은 분산 중첩이라 "수프에 녹은 소금값 정산" 문제.
- 격리층(모듈 단위 기여)이 면역·망각·**정산**을 동시에 해결 — 수렴 신호.

### 1.14 게이밍 논쟁 → 유인합치성 (사용자 반박이 프레임 교정)
- 사용자: "게이밍이 문제면 그건 시장 설계의 한계다." → 정확함.
- 메커니즘 디자인 관점: 게이밍 가능 = 가격 신호가 진짜 가치와 어긋난 증거.
  유튜브 낚시썸네일 = 주의(attention)를 가격 신호로 쓴 설계 귀결.
- 지식 시장의 구조적 이점: 기여 가치가 **사후 실측됨**(성능 개선) →
  지연된 진짜 신호 존재 → 예측시장 구조와 동형.
- 한계 명시: 불가능성 정리들(Myerson-Satterthwaite) → 목표는 게이밍 소멸이
  아니라 "정직한 기여의 기대수익이 게이밍을 구조적으로 압도".
- 관문의 손상 판정과 시장의 가치 산정 = **같은 함수의 두 얼굴**
  ("지연된 실측 신호를 현재 판정으로 번역").

### 1.15 KnowledgeNet 접합 (결정적 발견)
- 레포가 4층 스택의 상위 3층을 이미 프로토타입:
  scoring.py(안목 기반 가격 = 예측시장 동형) · verification.py(검증 닻 =
  지연 실측 번역 함수) · 스테이킹/에스크로(경제적 면역) · governance.py(분권).
- 더 깊은 발견: KnowledgeNet은 명세 2번(기질)에 정반대 답 — 이산 노드(서랍)
  vs 분산 중첩(수프). 이 선택이 정산(귀속 자명) · 망각(잠복/부활) · 자기 정의
  (보호 대상 = 검증된 온톨로지)를 연쇄 해소.
- 한계: 망각을 푸는 게 아니라 **우회**. 모델은 여전히 동결. 남는 문제 둘 —
  온톨로지 → 모델 능력의 경로(RAG+에 머물면 임시 메모리 한계 상속) ·
  **암묵지 병목**(시뮬레이션이 자체 노출: "카토의 손끝 지식 끝내 안 풀림").

## 2. 현재 아키텍처 그림 (4층 스택)

```
[기여 시장]   유인합치적 지식 가격 (KnowledgeNet: scoring/economy)  ← 있음
[거버넌스]    결정권 분산 (KnowledgeNet: governance)                ← 있음
[면역 관문]   손상 판정·음성 선택·격리 (KnowledgeNet: verification/
              staking = 경제적 면역, 부분)                          ← 부분
[가소성 층]   검증 통과 지식을 가중치로 파국 없이 통합              ← 미해결
              = 이 세미나의 대상
```
접합부: **검증 닻 통과 온톨로지 노드 → 학습 큐 → 가소성 메커니즘 → 가중치 통합**

관통하는 공통 미해결: "지연된 실측 신호를 적대적 환경에서 현재 판정으로
번역하는 함수" (관문 = 시장 = 동일 문제).

## 3. 세미나 커리큘럼 (이론 선행 트랙)

역할 재정의: "지속학습 공부"가 아니라 **현 체제가 다섯 명세에 내놓은 답과
실패 지점의 해부** (대안 설계의 전제).

1. 안정성-가소성 딜레마 (Grossberg; French 1999) ← **다음 세션, 미시작**
2. 경사하강+분산표현의 간섭 수학 (loss landscape 곡률, 그래디언트 간섭/GEM,
   EWC의 Fisher 근사와 실패)
3. 표현 이론: 중첩 가설·polysemanticity (Elhage et al. Toy Models of
   Superposition) + pseudo-forgetting 논쟁
4. 생물학적 해법의 계산 이론 (CLS; 시냅스 통합; 신경조절 게이팅; 희소 코딩)
5. 해법 분류학과 실패 양상 (정규화/리허설/아키텍처/최적화 계열; LLM CL 서베이)

병행 허용: 세션 3쯤부터 이해 가속용 소실험(2층 MLP 순차학습 관찰)은
"코드 프로젝트"가 아니라 이해 도구로 인정.

## 6. 추가 세션 (같은 날 후반부)

### 6.1 지식층/능력층 구분
- 사용자 질문 "모델이 동결인가? 피드백이 노드를 만들지 않나?" → 구분 확립:
  **지식 층(온톨로지)은 살아있고, 능력 층(가중치)은 동결.** RAG 한계 3:
  읽기≠능력(조합·전이 약함) · 검색 병목 · 암묵 패턴 비전달.

### 6.2 전략 확정 과정 (중력 사례 2건 추가)
- 중력 사례 3: 기존 사전학습 모델을 몸체로 전제(RAG+/어댑터)로 회귀 → 기각.
- 중력 사례 4(과교정): 백지 출발로 해석 → 기각.
- **최종 전략**: 동결 기저 LLM(교체 가능 부품) + 사용자 참여형 상부 신경망
  (구조 혁신의 전장). "스케일은 남의 전쟁, 우리는 그 위에 누적되는 것을
  소유한다."

### 6.3 H2A2H2 통합
- 레포 확인(공개 전환 후 API로 독해): 3-패널 지식 에디터. 대화 → 촘스키
  P→I→C(전제→추론→결론) 구조 포획 → 승인 패치 → 그래프 → 발행/투자(±1).
- 위치 확정: **3-레포 파이프라인** H2A2H2(포획) → KnowledgeNet(검증·가격)
  → 가소성 층(체화, 미해결).
- 핵심 수확: 상부망 훈련 신호 가설 = "다음 토큰"이 아니라 **검증된 추론
  그래프**. 한계: 비명제 지식(절차·감각)은 P→I→C에 안 담김.

### 6.4 접합 문제 교정
- 사용자 정식화: 인간 질문 → LLM 대답 → 가치 증분 or 그대로 채택 (문답
  소유자=사용자). **산출물 층위 접합 → 기저 완전 독립.** 내부 표현 접합은
  후순위 옵션으로 강등. 남는 문제는 라우팅.

### 6.5 산호초 모델 (역방향 — 정본 은유 채택)
- Claude 초기 매핑(폴립=LLM 문답, 골격=우리 축적층)을 사용자가 반전:
  **기저 LLM=기존 안정층(인류 문헌의 석회화), 우리=폴립층(활성면),
  우리 로직 통과 시 안정층 승격.**
- 승격 3경로: (a) 온톨로지 정본 (b) 상부망 가중치 체화 (c) 장기: 차세대
  기저 LLM 훈련 데이터로 편입 (문명 규모 루프 폐쇄).
- 검증 닻+시장+관문 = 하나의 **석회화 판정 기관**으로 통합 재인식.
- 생태 유사 4중 수렴: 산호초 / 토양 / 과학 문헌 / CLS(해마-신피질).
- 세션 1(안정성-가소성 딜레마)의 재주소: **승격 공정의 이론.**

### 6.6 방향 종합 (사용자 요청 "다 종합하면 방향이 뭐지")
한 문장: **인간-AI 대화에서 태어나는 지식을 구조로 포획하고, 시장으로
검증하고, 신경망으로 체화시키는 살아있는 집단 학습 시스템.**
뒤집는 세 독점: 학습 시점(동결→지속) · 학습 대상(랩 큐레이션→시장) ·
가치(무상 수취→기여 정산).
