> 3중 구조(동결 기저 LLM / 사용자 참여형 상부 신경망 / 심볼릭 온톨로지)의
> 설계 정본. 상태: 초안 — 세미나 진행에 따라 갱신. 확신도 표기 유지.
> 위치: `CAMS-KnowledgeNet/docs/design/plasticity-layer-spec.md`

> 산호초 모델(역방향) 채택, 접합 트레이드오프 교정.

## 0. 전략 원칙 (한 줄)

**스케일은 남의 전쟁, 우리는 그 위에 누적되는 것을 소유한다.**
기저 LLM은 스케일 경쟁의 산물을 소비하는 교체 가능 부품. 우리 자산은
상부망 가중치 + 검증된 온톨로지이며, 기저를 갈아끼워도 살아남는다.
성장 축: 컴퓨트가 아니라 **검증 지식의 축적 속도**.

## 1. 정본 은유: 산호초 (역방향)

```
[우리 폴립층]   인간-AI 문답·증분·검증이 일어나는 살아있는 활성면 (얇음)
      │ 승격 (our logic = 석회화 판정)
      ▼
[신규 안정층]   검증 통과 지식이 굳는 층 — (a) 온톨로지 정본
                (b) 상부망 가중치 체화  (c) 장기: 차세대 기저 훈련 데이터
      ▼
[기존 안정층]   동결 기저 LLM = 인류 문헌이 석회화된 기존 초 (두꺼움, 죽어있음)
```

- 기저 LLM = **기존 안정층**. 인류 텍스트의 압축·석회화. 동결이므로 손상 불가.
- 우리 시스템 = **폴립층**. 죽은 초의 표면에 다시 생명을 붙이는 활성층.
- 시스템의 성장 = **활성층의 안정층 승격**. 산호초가 자라는 방식 그대로.
- 생태 유사(수렴 확인): 산호초 / 토양 형성(분해자=면역 관문) / 과학 문헌
  (피어리뷰=승격 판정) / niche construction. 신경과학 CLS(해마-신피질)와
  동일 구조 — 4중 수렴 신호.
- 은유 한계(§4): 우리 안정층은 완전히 죽지 않고 재평가·잠복·부활하는
  "느리게 사는 층" (CLS와 재접속).

## 2. 3-레포 파이프라인 (승격 공정)

```
H2A2H2         대화 → P→I→C 추론 구조 포획 (증발 방지)      [프로토타입 존재]
   ▼
KnowledgeNet   검증·가격·배당 — 스테이킹, 안목 보상,        [프로토타입 존재]
               외부 현실 닻, 거버넌스 = 석회화 판정 기관
   ▼
가소성 층       검증 지식의 신경 안정층 체화                 [미해결 — 세미나 대상]
   ▼
환류            실측 기여도 → 기여자 배당 → 다음 기여 유인
```

- **승격 판정 기관의 통합 정체**: 검증 닻 + 유인합치 시장 + 면역 관문은
  별개 부품이 아니라 하나의 석회화 판정 기관.
- **관통 미해결**: "지연된 실측 신호를 적대적 환경에서 현재 판정으로
  번역하는 함수" (관문 = 시장 = 동일 문제).

## 3. 기저-상부 접합 (교정됨)

- **채택: 산출물 층위 접합.** 인간 질문 → 기저 LLM 대답 → 가치 증분
  (교정·보강·구조화) 또는 그대로 채택. 문답의 소유자는 사용자.
- 귀결: **기저 완전 독립** — 기저 교체 시 상부 자산 무손상. v0.1의 접합
  트레이드오프 경고는 내부 표현 개입을 전제한 것이었으므로 철회.
- 내부 표현 접합(steering 등)은 필수가 아닌 **후순위 최적화 옵션**으로 강등.
- 남는 설계 문제: **라우팅** — 어디까지 기저 답을 그대로 쓰고 어디서
  상부망이 개입하는가. 실질 성능의 결정 변수.

## 4. 상부망 설계 (미해결 심장부)

- **훈련 신호 가설**: "다음 토큰"이 아니라 **검증된 추론 그래프(P→I→C)**.
  평평한 텍스트=관찰 데이터, 추론 구조=추론 자체의 데이터 (Pearl 층위 상승).
- **크기 이점**: 상부망은 기저보다 작음 → 비-역전파 학습 규칙(국소 학습,
  검증신호-게이팅, Hebbian 변형)이 실전 투입 가능한 전장.
- **게이팅 가설**: 스테이킹/검증 강도 = 인공 신경조절물질 — 검증 강도가
  학습 강도(가소성)를 직접 조절.
- **내용물 후보**: 노드 횡단 암묵 패턴 · 지식 동원 라우팅 · 도메인 교정.
- P→I→C 한계(§4): 절차적·감각적 지식은 명제 구조에 안 담김 — 암묵지
  병목 재등장. 비명제적 지식의 포획 경로는 열린 문제.

## 5. 다섯 명세 채점표

| 명세 | 현 시스템의 답 | 미결 |
|---|---|---|
| 1 신용 할당 | 노드 이산 → 귀속 자명 · 검증신호 게이팅 | 상부망 내부 할당 규칙 |
| 2 지식 기질 | 3중: 기저(수프,동결)+온톨로지(서랍)+상부망 | 3중 기질의 분업 원리 |
| 3 안정성-가소성 | 승격 공정 자체가 답의 형태 | 승격 메커니즘=세미나 대상 |
| 4 시간 취급 | 스트림 일급 (기여 순서·잠복·부활) | 순차 통합 알고리즘 |
| 5 스케일 경로 | 기저=남의 스케일 · 우리=지식 축적 속도 | 상부망 규칙의 스케일 |

## 6. 미해결 문제 스택

1. 손상 판정 함수 (보호 능력 명세·시험) [당장 실험 가능]
2. 음성 선택의 보수성 편향 (쿤 문제)
3. 관문의 적응 학습 재귀 (부분 답: 외부 현실 닻로 순환 폐쇄; 일반화 미결)
4. 자기(self)의 계산적 정의 (부분 답: 자기=검증된 온톨로지; 능력 차원 미결)
5. 암묵지 병목 (비명제 지식의 포획 — H2A2H2 상류에서도 재등장)
6. **승격 (b) 경로**: 검증된 폴립을 신경 안정층으로 굳히는 메커니즘
   = 가소성 층 본체 = 세미나의 표적

## 7. 합의된 설계 원칙

- 판정 기준: novelty 아닌 **손상** (danger model)
- 망각 방지 = 오염 방어 (동일 메커니즘: 자기 손상 시험)
- 시장 목표: 게이밍 소멸 아닌 **유인합치** (정직 기여의 기대수익이 압도)
- 가격 신호: 대리변수(주의) 아닌 **사후 실측 가치** (예측시장 동형)
- 학습 대상 결정권: 랩 독점 → 시장+검증+거버넌스 **분산**
- 격리(기여 단위 모듈): 면역·망각·정산 동시 해결 — 유지
- 접합: 산출물 층위 → **기저 독립성** 확보
