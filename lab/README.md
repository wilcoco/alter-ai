# /lab — 가소성 실험 트랙

**승격 (b)경로 연구.** 검증을 통과한 폴립을 *온톨로지 정본*이 아니라
**신경 안정층(가중치)** 으로 굳히는 메커니즘 — spec §6-6, 세미나의 표적.

## 격리 규약 (위반 금지)

- `/lab` 은 `/app` 을 **import 해도 된다** (도메인 코어를 실험 재료로 쓴다).
- `/app` 은 `/lab` 을 **절대 import 하지 않는다.** 실험 코드가 서비스 트랙을
  오염시키면 안 된다. `tests/test_isolation.py` 가 이 방향성을 강제한다.
- lab 의 결과가 app 에 들어가려면 채팅 세미나 합의 → docs 반영 → app 구현의
  순서를 거친다. 코드가 먼저 새어 들어오지 않게 한다.

## 현재 상태

`promotion_b_sketch.py` — **실험 하네스일 뿐, 답이 아니다.** 승격 (b)경로가
풀렸다고 주장하지 않는다. 지금 있는 것은 spec §4 의 "검증 강도 = 인공
신경조절물질(가소성 게이팅)" 가설을 *관찰 가능한 형태로 세워둔 것*이다.

실측 (`python lab/promotion_b_sketch.py`, seed 20260819):

| 모드 | A 학습 후 | B 학습 후 A | 망각량 | B 최종 |
|---|---|---|---|---|
| 게이팅 없음 | 0.00009 | 0.27851 | **0.27843** | 0.00569 |
| 게이팅 있음 | 0.00009 | 0.25551 | **0.25542** | 0.11454 |

읽어야 할 것은 **게이팅이 거의 듣지 않는다**는 사실이다. 망각은 8% 줄었을
뿐인데 새 지식 학습은 20배 나빠졌다. 즉 이 게이팅은 딜레마를 완화한 것도
아니고 그냥 **손잡이를 안정성 쪽으로 조금 돌린 것**이다 — 세션 1 의 판정
("완화책은 전제를 제거하지 않고 약화시킬 뿐")이 여기서도 그대로 나온다.

원인은 분명하다: 여기 구현된 게이팅은 **전역 스칼라 학습률 배수**라서, 뇌의
신경조절이 하는 *국소성*("언제 **어디를** 말랑하게")이 통째로 빠져 있다
(§A7: 정적 구획만으로는 부족하고 게이팅·조절 시스템이 필수라는 논증의 역방향
확인). 국소성 없는 게이팅은 안정성-가소성 손잡이를 한 칸 옮길 뿐이다.

진짜 표적 — "전역 경사하강 없이 검증 노드 하나를 가중치에 통합하는 최소
메커니즘" — 은 손도 대지 않았다.

## 미해결 (spec §6 / §8)

- 전역 경사하강 없이 노드 하나를 통합하는 최소 메커니즘
- 3중 기질(기저 수프 / 온톨로지 서랍 / 상부망)의 분업 원리
- 라우팅: 기저 답 채택 vs 상부 개입의 판별 함수
- 비명제(절차·감각) 지식의 포획과 체화 경로
